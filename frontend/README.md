# Frontend (LaBella)

Vitrine em React + TypeScript (Vite, TanStack Router/Query).

## Desenvolvimento

```bash
cp .env.example .env
npm install
npm run dev
```

Configure `VITE_API_BASE_URL` apontando para o backend (ex.: `http://localhost:8000`).

## Build

```bash
npm run build
```

## Lint / formatação

```bash
npm run lint
npm run format
```
